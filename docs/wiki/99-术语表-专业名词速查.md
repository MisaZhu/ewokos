# 附录：专业术语速查表

> 本表收录教程中出现的全部缩写与专业名词。
> 每个词条给出：**英文全称 → 中文含义 → 一句话解释 → 首次出现的章节**。
> 阅读正文时遇到不认识的词，回来查这里；也可当手册用。

## 一、硬件与总线类

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **UART** | Universal Asynchronous Receiver/Transmitter | 通用异步收发器，即"串口"。按固定波特率逐位发送/接收字符，无需时钟线，只需 TX/RX/GND 三根线。 | 02/03 章 |
| **MMIO** | Memory-Mapped I/O | 内存映射 I/O。把设备控制寄存器映射成一段内存地址，读写该地址即操作硬件，是 ARM 控制外设的标准方式。 | 03 章 |
| **GPIO** | General Purpose Input/Output | 通用输入输出引脚，软件可配置为输入或输出。串口的 TX/RX 即复用自两个 GPIO。 | 02 章 |
| **FIFO** | First In First Out | 先入先出缓冲。串口收发各带一个小 FIFO，避免 CPU 逐字节等待。 | 03 章 |
| **Baud rate** | — | 波特率，串口每秒传输的位数。本教程统一 115200。 | 02 章 |
| **SD / SDHC** | Secure Digital | 安全数字卡，树莓派的存储介质，按 512 字节扇区读写。 | 10 章 |
| **EMMC** | Embedded MultiMediaCard | 嵌入式多媒体卡控制器，Pi2/Pi3 上 SD 卡所挂的控制器。 | 10 章 |
| **Mailbox** | — | 邮箱，树莓派 CPU 与 GPU 之间的硬件消息队列，用于申请帧缓冲、查询时钟等。 | 13 章 |
| **Framebuffer** | — | 帧缓冲，一块按行存放像素颜色的内存，写入即显示。 | 13 章 |
| **DMA** | Direct Memory Access | 直接内存访问。硬件引擎不经过 CPU 直接在内存与设备间搬数据。 | 09/13 章 |
| **Timer** | — | 定时器，周期性产生中断，是操作系统"时间"的来源。 | 06 章 |
| **IRQ / FIQ** | Interrupt Request / Fast Interrupt Request | 中断请求 / 快速中断请求，ARM 两类硬件中断。 | 06 章 |
| **GIC** | Generic Interrupt Controller | 通用中断控制器，ARM 标准的中断分发硬件，负责仲裁与路由中断到各核。 | 06 章 |
| **EOI** | End Of Interrupt | 中断结束。处理完中断必须向控制器发送的信号，否则该中断不会再上报。 | 06 章 |
| **Watchdog** | — | 看门狗定时器，超时未喂则复位系统。EwokOS 用它兜底"IPC 服务卡死"。 | 09 章 |

## 二、CPU 架构与运行状态

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **AArch64 / ARMv8** | — | ARM 64 位架构。本教程主要目标（Pi3/Pi4）。 | 01 章 |
| **EL0~EL3** | Exception Level 0~3 | 异常级别，即 ARM 的四个特权级。EL0=用户态，EL1=内核（OS）,EL2=虚拟化，EL3=安全监控。 | 04 章 |
| **SPSR / ELR** | Saved Program Status Register / Exception Link Register | 保存的程序状态寄存器 / 异常链接寄存器。异常发生时自动保存现场、记录返回地址。 | 04 章 |
| **VBAR** | Vector Base Address Register | 向量基址寄存器，指向异常向量表。 | 04 章 |
| **eret** | Exception Return | 异常返回指令，恢复现场并回到触发异常的代码（或进入用户态）。 | 04 章 |
| **svc** | Supervisor Call | 系统调用指令，用户态主动陷入内核的唯一入口。 | 08 章 |
| **AAPCS64** | ARM Architecture Procedure Call Standard | ARM 64 位函数调用约定：参数放 x0~x7，返回值在 x0。 | 03 章 |
| **LR / FP** | Link Register / Frame Pointer | 链接寄存器（x30，存返回地址）/ 帧指针（x29，标记栈帧）。 | 03 章 |
| **context** | — | 上下文，一个执行流的完整寄存器快照，是调度与切换的基本单位。 | 07 章 |
| **SMP** | Symmetric Multi-Processing | 对称多处理，多个对等 CPU 核心同时运行。Pi3/Pi4 为 4 核。 | 07 章 |

## 三、内存管理

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **MMU** | Memory Management Unit | 内存管理单元，CPU 内把虚拟地址翻译成物理地址的硬件。 | 05 章 |
| **VA / PA** | Virtual / Physical Address | 虚拟地址 / 物理地址。 | 05 章 |
| **Page / 页** | — | 内存管理的最小单位，EwokOS 为 4KB。 | 05 章 |
| **Page Table / 页表** | — | 记录"虚拟页 → 物理页 + 权限"的翻译表，由内核维护。 | 05 章 |
| **PTE** | Page Table Entry | 页表项，一条"虚拟页→物理页"的映射记录，含权限与属性位。 | 05 章 |
| **TLB** | Translation Lookaside Buffer | 页表翻译缓存，硬件缓存最近的地址翻译以加速。 | 05 章 |
| **TTBR0/TTBR1** | Translation Table Base Register | 页表基址寄存器。TTBR0 管低地址（用户），TTBR1 管高地址（内核）。 | 05 章 |
| **SCTLR** | System Control Register | 系统控制寄存器，含开关 MMU/缓存的位。 | 05 章 |
| **MAIR** | Memory Attribute Indirection Register | 内存属性间接寄存器，定义"可缓存内存/设备内存"等属性。 | 05 章 |
| **CoW** | Copy-On-Write | 写时复制。fork 时父子共享物理页，谁先写谁才复制，靠页引用计数实现。 | 05/07 章 |
| **页引用计数** | — | `_pages_ref` 数组，记录每个物理页被几个页表引用，是 CoW 的依据。 | 05 章 |
| **kalloc** | — | 内核物理页分配器，以 4KB 页为单位，兼管 1KB 小块。 | 05 章 |
| **kmalloc** | — | 内核堆，分配任意大小小对象，类似用户态 malloc。 | 05 章 |
| **shm** | Shared Memory | 共享内存，两进程映射同一物理页，用于零拷贝传大数据。 | 09/13 章 |
| **缺页异常** | Page Fault | 访问了无映射的虚拟页触发的异常，内核借此按需分配物理页。 | 05 章 |

## 四、进程与调度

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **进程 / Process** | — | 一个正在运行的程序实例，=代码+数据+上下文。 | 07 章 |
| **pid / uid / uuid** | process/user id, universal unique id | 进程号 / 用户号 / 全局唯一标识（进程号会复用，uuid 不会）。 | 07 章 |
| **READY/RUNNING/BLOCK/SLEEP/ZOMBIE** | — | 进程状态机：就绪/运行/阻塞/睡眠/僵尸。 | 07 章 |
| **fork** | — | 复制当前进程生成子进程，返回两次（父得子 pid，子得 0）。 | 07 章 |
| **exec** | — | 用新程序替换当前进程的代码与数据。 | 11 章 |
| **调度器 / scheduler** | — | 决定下一个上 CPU 的进程。EwokOS 用简单轮转。 | 07 章 |
| **上下文切换** | Context Switch | 保存当前进程寄存器、装载另一进程寄存器的过程。 | 07 章 |
| **Zombie / 僵尸** | — | 已退出但未被父进程回收的进程，占一个进程表项。 | 07 章 |
| **内核劫持** | — | 单任务 IPC 模式下，内核直接借用服务进程的主上下文执行回调。 | 09 章 |

## 五、IPC 与微内核

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **IPC** | Inter-Process Communication | 进程间通信，微内核的核心机制。 | 09 章 |
| **RPC** | Remote Procedure Call | 远程过程调用，IPC 的"请求-应答"模型即本地化的 RPC。 | 09 章 |
| **proto_t** | protocol | EwokOS 的 IPC 数据打包结构，变长、自描述、可跨进程拷贝。 | 09 章 |
| **ipc_task_t** | — | 一次 IPC 请求在内核的槽位，含调用方信息、参数、状态。 | 09 章 |
| **ipc_server_t** | — | 服务进程的 IPC 状态：入口地址、任务槽数组、等待队列、线程池。 | 09 章 |
| **call_id** | — | IPC 命令号，标识调用的是服务的哪个功能。 | 09 章 |
| **IPC_LAZY / IPC_NON_RETURN** | — | 调用修饰位：懒调度 / 无需返回值（单向通知）。 | 09 章 |
| **IPC_MULTI_TASK / MULTI_CORE** | — | 多线程/多核服务标志，决定用线程池并发处理请求。 | 09 章 |
| **单任务服务** | — | 内核劫持主上下文串行处理请求的服务（如多数驱动）。 | 09 章 |
| **线程池 / pool** | — | 多线程服务按需孵化、复用的一组工作线程。 | 09 章 |
| **微内核 / Microkernel** | — | 内核只保留最小功能（调度/内存/中断/IPC），其余全放用户态。 | 01 章 |
| **宏内核 / Monolithic** | — | 驱动、文件系统都编译进内核的传统架构（如 Linux）。 | 01 章 |
| **用户态驱动** | — | 以普通进程形式运行、通过 IPC 对外提供服务的驱动。 | 01/09 章 |

## 六、文件系统

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **VFS** | Virtual File System | 虚拟文件系统，统一"一切皆文件"的抽象层（路径→服务）。 | 10 章 |
| **inode** | index node | 索引节点，文件的"档案"：大小、权限、数据块指针，不含文件名。 | 10 章 |
| **ext2 / ext3** | Second/Third Extended filesystem | 经典 Linux 文件系统格式。EwokOS 用它组织 SD 卡。 | 10 章 |
| **超级块 / superblock** | — | 文件系统的全局元信息：块大小、inode 数、魔数等。 | 10 章 |
| **块组 / block group** | — | ext2 把磁盘分成的管理单元，各含位图、inode 表、数据块。 | 10 章 |
| **块位图 / inode 位图** | — | 标记哪些块/ inode 已被占用的位数组。 | 10 章 |
| **目录项 / dir entry** | — | 目录文件里的一条"文件名 → inode 号"记录。 | 10 章 |
| **扇区 / sector** | — | 块设备读写的最小单位，SD 卡为 512 字节。 | 10 章 |
| **块 / block** | — | 文件系统读写的最小单位，ext2 常为 1KB/4KB。 | 10 章 |
| **MBR / GPT** | Master Boot Record / GUID Partition Table | 两种磁盘分区表格式，记录分区起始位置。 | 10 章 |
| **挂载点 / mount** | — | 把一个文件系统服务接到目录树某节点。 | 10 章 |
| **vfsd / sdfsd / ramfsd** | — | 路由器 / SD-ext2 服务 / 内存盘服务。 | 10 章 |

## 七、图形与窗口

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **graph_t** | — | 画布结构：像素缓冲（常为共享内存）+ 宽高 + 裁剪区。 | 13 章 |
| **g2d** | 2D Graphics Engine | 2D 图形加速，把填充/位图拷贝等操作交给专用引擎。 | 13 章 |
| **blt / blit** | Block Transfer | 块传送，把一块像素从源画布拷到目标画布。 | 13 章 |
| **合成 / compositing** | — | 把多个窗口画布按层级叠加成最终屏幕画面的过程。 | 13 章 |
| **xserverd** | — | X 风格窗口服务器：维护窗口树、合成、分发输入事件。 | 13 章 |

| **ARGB** | Alpha-Red-Green-Blue | 每像素 32 位：8 位透明度+三通道颜色。 | 13 章 |

## 八、通用概念

| 术语 | 英文全称 | 含义与解释 | 出现于 |
|---|---|---|---|
| **ELF** | Executable and Linkable Format | 可执行与可链接格式，Linux/Unix 通用的程序二进制格式。 | 07 章 |
| **BSS** | Block Started by Symbol | 未初始化全局数据段，加载时清零，不占镜像空间。 | 03 章 |
| **链接脚本 / lds** | linker script | 告诉链接器各段放内存何处的配置文件。 | 03 章 |
| **交叉编译** | Cross-compile | 在一种机器（如 Mac）上编译出另一种机器（ARM）能跑的程序。 | 02 章 |
| **工具链 / toolchain** | — | 交叉编译器+汇编器+链接器的集合（如 aarch64-none-elf-gcc）。 | 02 章 |
| **QEMU** | Quick Emulator | 开源硬件模拟器，免真机即可运行系统。 | 02 章 |
| **rootfs** | Root Filesystem | 根文件系统镜像，含系统所有文件，烧进 SD 卡。 | 12 章 |
| **init** | — | 1 号进程，所有用户进程的祖先，负责拉起整个系统。 | 11 章 |
| **shell** | — | 命令行解释器，读取用户输入并执行命令。 | 11 章 |
| **自旋锁 / spinlock** | — | 忙等待式互斥锁，适合内核短临界区（尤其 SMP）。 | 07/09 章 |
| **临界区** | Critical Section | 同一时刻只允许一个执行流进入的代码段。 | 07 章 |
| **原子操作** | Atomic | 不可被中断、要么全做完要么不做的操作。 | 07 章 |

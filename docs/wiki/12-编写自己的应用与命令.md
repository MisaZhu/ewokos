# 12 编写自己的应用与命令

> 本章目标：亲手写一个命令行程序，加入构建系统，打包进镜像，
> 在 EwokOS 里运行它。这是你第一次以"开发者"身份给这个系统添砖加瓦。

## 12.1 用户态程序的运行环境

先搞清楚"在 EwokOS 上写 C 程序"和"在 Linux 上写 C 程序"的差别：

| 你在 Linux 上 | 在 EwokOS 上 |
|---------------|--------------|
| `#include <stdio.h>` 用 glibc | 用 EwokOS 自己的 C 库 |
| 系统调用走 Linux ABI | 走 `svc #0` + EwokOS 系统调用表（第 08 章） |
| 编译器 = 本机编译器 | 交叉编译器 `aarch64-none-elf-gcc` |

EwokOS 的 C 库由两部分组成（[system/basic/libc/](../../system/basic/libc/)）：

- **`libewoksys`**：系统接口层。系统调用封装（`syscall0~3`）、
  IPC 客户端/服务端、`proto_t`、fork/exec、打开文件等；
- **`libgloss`**：C 标准库的"胶水"。`printf`、`malloc`、`memcpy`、
  `newlib` 风格的运行时，最终把标准函数接到 `libewoksys` 上。

构建系统把两者链接成 `EWOK_LIBC`，你的程序直接链接它即可。

## 12.2 看一个现成的例子：echo

目录 [system/basic/bin/echo/](../../system/basic/bin/echo/) 结构极简：

```
echo/
├── echo.c        # 源代码（就是普通 C 程序）
├── Makefile
└── aarch64/      # 编译产物按架构分目录存放
```

它的 [Makefile](../../system/basic/bin/echo/Makefile)：

```make
SYS_DIR=../../..
include $(SYS_DIR)/platform/$(ARCH)/make.rule   # 编译器与通用规则

BUILD_DIR = $(SYS_DIR)/build_$(ARCH)/$(HW)      # 本架构本板子的构建目录
TARGET_DIR = $(BUILD_DIR)/rootfs                # 最终 rootfs 目录

LDFLAGS = -L $(BUILD_DIR)/lib
CFLAGS += -I $(BUILD_DIR)/include

ECHO_OBJS = $(ARCH)/echo.o
ECHO = $(TARGET_DIR)/bin/echo

$(ECHO): $(ECHO_OBJS) $(BUILD_DIR)/lib/libewoksys.a
	$(LD) -Ttext=100 $(ECHO_OBJS) -o $(ECHO) $(LDFLAGS) $(EWOK_LIBC)
```

三个细节值得注意：

1. **`-Ttext=100`**：用户程序被加载到虚拟地址 `0x100`
   （低地址空间的最底部附近），与内核高地址井水不犯河水（第 05 章）；
2. **`$(EWOK_LIBC)`**：链接完整的 C 库；
3. 产物直接写进 `rootfs/bin/`，之后会被 `make sd` 打包进镜像。

## 12.3 跟着做：写一个 `hello` 命令

### 第 1 步：源代码

创建 `system/basic/bin/hello/hello.c`：

```c
#include <stdio.h>
#include <stdlib.h>
#include <unistd.h>
#include <ewoksys/klog.h>

int main(int argc, char** argv) {
    printf("Hello from my first EwokOS app!\n");
    printf("argc = %d\n", argc);
    for(int i = 0; i < argc; i++)
        printf("  argv[%d] = %s\n", i, argv[i]);

    printf("my pid = %d\n", getpid());
    return 0;
}
```

`printf`、`getpid` 这些熟悉的名字背后，是第 08、09 章你刚学过的机制。

### 第 2 步：Makefile

创建 `system/basic/bin/hello/Makefile`（把 echo 的抄过来改名即可）：

```make
SYS_DIR=../../..
include $(SYS_DIR)/platform/$(ARCH)/make.rule

BUILD_DIR = $(SYS_DIR)/build_$(ARCH)/$(HW)
TARGET_DIR = $(BUILD_DIR)/rootfs

LDFLAGS = -L $(BUILD_DIR)/lib
CFLAGS += -I $(BUILD_DIR)/include

HELLO_OBJS = $(ARCH)/hello.o
HELLO = $(TARGET_DIR)/bin/hello

$(HELLO): $(HELLO_OBJS) $(BUILD_DIR)/lib/libewoksys.a
	$(LD) -Ttext=100 $(HELLO_OBJS) -o $(HELLO) $(LDFLAGS) $(EWOK_LIBC)

clean:
	rm -f $(HELLO_OBJS)
```

### 第 3 步：注册进构建系统

编辑 [system/basic/bin/Makefile](../../system/basic/bin/Makefile)，
在 `DIRS = cp ipcserv bgrun ... echo sleep ...` 这一行的末尾加上 `hello`。

### 第 4 步：构建并运行

```bash
> cd machines/raspix/system
> make basic      # 只重建基础层（快）。首次或大改后建议 make 全量
> make sd         # 把 rootfs 打包进 SD 镜像
> make run
```

系统起来后：

```
> hello a b c
Hello from my first EwokOS app!
argc = 4
  argv[0] = hello
  argv[1] = a
  argv[2] = b
  argv[3] = c
my pid = 42
```

> **避坑提醒**：只 `make` 驱动或应用目录，**不会**自动更新烧录/运行用的
> 镜像文件。改完代码必须回到 `machines/raspix/system` 重新 `make sd`，
> 否则跑的还是旧程序。

## 12.4 进阶玩法

### 调用系统能力

你的程序可以使用整个系统接口：

```c
// 读文件（经过 vfsd）
FILE* f = fopen("/etc/passwd", "r");

// 获取服务并 IPC 调用（第 09 章）
proto_t in, out;
proto_init(&in, ibuf, sizeof(ibuf));
proto_init(&out, obuf, sizeof(obuf));
ipc_call(get_serv_pid("vfs"), VFS_CMD_GET_STATE, &in, &out);

// 创建子进程
int pid = fork();
if(pid == 0) {
    proc_exec("ls /");
}
```

### 写一个自己的驱动服务

参照 [system/basic/drivers/](../../system/basic/drivers/) 下的
`nulld`（最简单的设备）或 `timerd`，核心套路：

```c
// 设备驱动 = 一个提供 /dev/xxx 文件的 IPC 服务
void ipc_step(...) {
    switch(cmd) {
    case DEV_CMD_READ:  ...  // 有人读 /dev/xxx
    case DEV_CMD_WRITE: ...  // 有人写 /dev/xxx
    }
}
```

写好后在 `init.rd` 里加一行 `@/bin/ipcserv /drivers/hello ...`，
重启后 `/dev/xxx` 就存在了。这是向"写驱动"迈出的第一步，
第 13 章会用同样的套路讲图形驱动。

## 12.5 动手练习

1. 给 `hello` 加功能：不带参数时打印系统信息（`sysinfo` 系统调用）；
2. 写一个 `sum` 命令：从标准输入读若干数字求和（练习管道与 `scanf`）；
3. 写一个极简驱动 `counterd`：提供 `/dev/counter`，每次读返回自增计数。
   参考 `nulld` 的代码结构。

## 12.6 本章小结

- 用户程序 = 普通 C 代码 + `EWOK_LIBC`（libewoksys + libgloss），
  加载到虚拟地址 `0x100` 起；
- 新增命令三步：源码、Makefile、注册进 `bin/Makefile` 的 `DIRS`；
- 改完必须 `make sd` 重新打包镜像；
- 驱动 = 用户态服务进程，与命令写法同源。

# 15 调试技巧与进阶路线

> 本章目标：掌握内核开发必备的调试手段，并给出完成教程之后的
> 进阶路线图。到这里，你已经走完了从裸机到完整操作系统的全程。

## 15.1 三条日志通道

EwokOS 的日志体系分三层（由低到高）：

| 通道 | 谁在用 | 输出到哪 |
|------|--------|----------|
| 内核 `printf`/`kout` | 内核代码 | 直接写 UART（串口），永远可用 |
| `klog`/`kout`（用户态） | 启动早期、紧急调试 | 走 `SYS_KPRINT` 系统调用打到内核串口 |
| `slog`/`sout`（用户态） | 正常运行期的程序 | 写入 `/dev/log`（logd 的 64KB 环形缓冲） |

用法（用户态程序）：

```c
#include <ewoksys/klog.h>
klog("urgent: %d\n", x);   // 直接打到内核串口（日志守护没起来时也能用）
slog("normal log: %s\n", s); // 写进 /dev/log
```

系统跑起来后可以读取日志缓冲：

```
> cat /dev/log
```

经验法则：**怀疑哪个环节，就在哪个环节的入口/出口加日志**。
内核级代码用 `printf`，用户态用 `slog`。

## 15.2 GDB 调试内核

QEMU + GDB 是内核调试的瑞士军刀（第 02 章装好了环境）：

```bash
# 终端 1
> cd machines/raspix/kernel
> make debug          # QEMU 停在第一条指令，等 GDB

# 终端 2
> make gdb            # 自动连接
```

常用操作：

```
(gdb) b _kernel_entry_c     # 在内核 C 入口打断点
(gdb) c                     # 继续
(gdb) b proc.c:800          # 按文件行号打断点
(gdb) bt                    # 看调用栈
(gdb) p *proc               # 打印结构体
(gdb) x/10i $pc             # 反汇编当前位置
```

技巧：
- `make asm` 生成 `kernel.asm` 完整反汇编，对照汇编查问题；
- 卡死时连上 GDB 按 `Ctrl-C`，`bt` 一眼看出卡在哪；
- 断点打在 `panic` / `halt` 附近可以抓住崩溃第一现场。

## 15.3 系统自带诊断命令

启动后常用的诊断工具：

```
> ps          # 进程列表：pid、状态、内存、CPU 时间
> svcinfo     # 已注册的 IPC 服务
> sysinfo     # 系统信息（内存、硬件）
> df          # 挂载表
> dump <pid>  # 转储指定进程的信息
> elfinfo     # 查看 ELF 文件结构（学习第 07 章时的好帮手）
> mmio        # 直接读写 MMIO 寄存器（调试驱动用）
```

## 15.4 常见坑速查表

| 症状 | 原因与解决 |
|------|-----------|
| 改了代码但行为没变 | 忘了 `make sd` 重新打包镜像（第 12、14 章强调过） |
| 编译报找不到编译器 | 工具链没装好/不在 PATH（第 02 章） |
| QEMU 一片黑 | 检查 `-serial` 参数；`Ctrl-A x` 退出 |
| 真机串口无输出 | 串口线交叉接反了；`config.txt` 缺 `enable_uart=1` |
| 真机起不来但 QEMU 正常 | 检查 `kernel8.img` 是否为该架构最新产物；Pi4 与 Pi3 的 MMIO 不同 |
| 系统起一半卡住 | 串口看最后一行日志，定位是哪个服务启动失败 |

## 15.5 进阶路线：接下来做什么

你已经掌握了主干。下面是由易到难的进阶方向：

### 入门级
1. **加一个系统调用**：在 `syscalls.h` 加编号、`svc.c` 加分支、
   `libewoksys` 加封装——走通"内核接口扩展"全流程；
2. **写一个自己的驱动**：如 GPIO LED 控制（`/dev/led`），
   参考第 12 章的设备服务套路；
3. **给 `hello` 加参数解析、颜色输出**，熟悉 shell 与终端能力。

### 进阶级
4. **读懂网络栈**（`system/network/`）：从网卡驱动到 TCP 分层，
   是微内核上完整协议栈的优秀样本；
5. **研究 CoW 与共享内存**（`kernel/kernel/src/mm/`）：
   写测试验证 fork 后的写时复制行为；
6. **SMP 多核**：读懂从核启动（`boot.S` 的 `slave_core`）、
   IPI 与自旋锁，试着改调度策略（如优先级队列）。

### 挑战级
7. **实现一个新文件系统**（如简易的 FAT），作为新的挂载点服务；
8. **给窗口系统写一个新主题/新应用**（参考 `projects/` 与 `sw.extra/`）；
9. **移植到新板子**：照着 `machines/` 里任一套写启动代码与驱动——
   这是操作系统工程师的毕业作品。

### 延伸阅读
- 《ARM Architecture Reference Manual (ARMv8-A)》——权威但厚重，按需查；
- 树莓派 BCM2837/BCM2711 外设手册——写树莓派驱动的必备；
- 经典教材：OSTEP（操作系统导论）、《现代操作系统》。
